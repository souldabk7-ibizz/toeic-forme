# TOEIC 770 Planner

แผนและสื่อการเรียนรู้ส่วนตัวเพื่อยกระดับคะแนน TOEIC จาก **510** (Reading 350 / Listening 160) ไปสู่เป้าหมาย **770**

## เริ่มใช้งาน

เปิดไฟล์ `webapp/index.html` ด้วยเบราว์เซอร์ (ดับเบิลคลิก หรือ `open webapp/index.html`) — ไม่ต้องติดตั้งอะไรเพิ่ม ไม่ต้องต่อเน็ต ข้อมูลทั้งหมด (คำศัพท์ที่จำได้, คะแนนที่บันทึก, วันเริ่มแผน) เก็บไว้ใน `localStorage` ของเบราว์เซอร์เครื่องนั้นเท่านั้น

แนะนำให้ใช้ Chrome หรือ Edge เพื่อให้ปุ่ม "▶ ฟัง" ในหน้า Listening ทำงานได้ (ใช้ Web Speech API อ่านออกเสียงให้ในตัว ไม่ต้องมีไฟล์เสียง)

ถ้าต้องการเปิดผ่านเซิร์ฟเวอร์ในเครื่อง (ไม่บังคับ):
```
cd webapp
python3 -m http.server 8080
# แล้วเปิด http://localhost:8080
```

## มีอะไรอยู่ในนี้

- **หน้า "วันนี้" (Dashboard)** — สรุปเป้าหมาย, เซสชันของวันนี้ตามสัปดาห์ที่อยู่ในแผน, ตัวจับเวลา 30 นาที, จำนวนคำศัพท์ที่ครบกำหนดทวน
- **หน้า "ศัพท์" (Vocabulary)** — คำศัพท์ TOEIC 240 คำ แบ่งเป็น 24 วันตามหมวดหมู่ที่ออกสอบบ่อย (คัดเลือกโดยอ้างอิงหมวดคำศัพท์ TOEIC ที่ใช้กันแพร่หลาย เช่น TOEIC Service List) โหมด "ทบทวนวันนี้" ดึงเฉพาะคำที่ครบกำหนดทวนจากทุกวันมาให้ทวนอัตโนมัติ พร้อม flashcard ระบบ Leitner spaced-repetition และปุ่มฟังเสียง 🔊 ทั้งคำและประโยคตัวอย่าง (กด "รู้แล้ว/ยังไม่รู้" ระบบจะเลื่อนคำนั้นไปทวนห่างขึ้นหรือถี่ขึ้นอัตโนมัติ) และแบบทดสอบ (Quiz) ท้ายวัน
- **หน้า "ไวยากรณ์" (Grammar)** — 10 บทเรียนไวยากรณ์ TOEIC Part 5/6 เรียงลำดับ ค่อยๆ เรียนทีละบท พร้อมคำอธิบาย ตัวอย่างประโยค (ฟังเสียงได้) และแบบฝึกหัดท้ายบท
- **หน้า Listening** — โจทย์ Part 2 (ถาม-ตอบสั้น), Part 3 (บทสนทนา), Part 4 (พูดคนเดียว/ประกาศ) 12 สัปดาห์ พร้อมปุ่มอ่านออกเสียงให้ฟัง (ปรับความเร็วปกติ/ช้าได้) — ใช้แทนไฟล์เสียงจริงเพื่อฝึกฟังได้ทุกที่
- **หน้า Reading** — โจทย์ Part 5 (เติมคำในประโยค), Part 6 (เติมคำในบทความ), Part 7 (อ่านจับใจความ) 12 สัปดาห์
- **หน้า "ข้อสอบชุด" (Mock Test)** — ข้อสอบเสมือนจริงแบบเต็มชุด (Listening + Reading) 5 ชุด ให้ทำแล้วตรวจคะแนนรวม
- **หน้า "แผน 12 สัปดาห์"** — ตารางรายวัน/รายสัปดาห์ทั้งหมด และจุดตรวจสอบ (checkpoint) ทุก 4 สัปดาห์
- **หน้า "ความคืบหน้า" (Progress)** — บันทึกคะแนนจากการสอบจำลอง (mock test) แต่ละครั้ง แล้วดูกราฟคะแนนรวมเทียบเป้าหมาย และกราฟเทียบ Reading/Listening
- **แบบทดสอบวันนี้** (ในหน้า Dashboard) — สุ่มโจทย์ผสมศัพท์ที่ต้องทบทวน + ไวยากรณ์ประจำวัน ให้ทำทุกวัน

## แนวคิดของแผน

- Listening (160) อ่อนกว่า Reading (350) มาก จึงเน้นฝึก Listening ถี่กว่าในแต่ละสัปดาห์ (จันทร์และพุธ) และ Reading วันอังคาร/พฤหัส ส่วนวันศุกร์เป็นแบบผสม (mini mock)
- 30 นาที/วัน ช่วง 21:00–22:00 (หรือเวลาไหนก็ได้ที่สะดวกในแต่ละวัน มากหรือน้อยกว่านี้ได้) แบ่งเป็น ~7 นาทีทวนศัพท์ + ~18 นาทีฝึกทักษะหลักของวันนั้น + ~5 นาทีสรุป
- การขยับจาก 510 ไป 770 (+260 คะแนน) ตามจริงมักใช้เวลา 4-6 เดือนของการฝึกสม่ำเสมอ ไม่ใช่ 12 สัปดาห์ แผนนี้คือ **Phase 1** สำหรับสร้างพื้นฐานคำศัพท์และวินัยการเรียน หลังจบสัปดาห์ที่ 12 ให้ทำซ้ำโครงสร้างเดิมเป็น Phase 2 พร้อมสอบจำลองเต็มรูปแบบเพิ่มเติม จนกว่าคะแนนจำลอง 2 ครั้งติดกันจะถึง 770

รายละเอียดฉบับอ่านง่าย/พิมพ์ได้ดูที่ [`STUDY_PLAN.md`](STUDY_PLAN.md)

## โครงสร้างไฟล์

```
webapp/
  index.html        โครงหน้าเว็บ
  style.css         ธีมสี (รองรับ light/dark ตามเบราว์เซอร์)
  app.js            ตรรกะทั้งหมด: SRS, ตัวจับเวลา, quiz, กราฟ, บันทึกคะแนน
  data/vocab.js      คำศัพท์ 24 วัน x 10 คำ (240 คำ)
  data/grammar.js    บทเรียนไวยากรณ์ 10 บท พร้อมแบบฝึกหัด
  data/mock.js       ข้อสอบชุดเสมือนจริง 5 ชุด
  data/listening.js  โจทย์ Listening 12 สัปดาห์
  data/reading.js    โจทย์ Reading 12 สัปดาห์
  data/plan.js       โครงสร้างแผนรายวัน/รายสัปดาห์/checkpoint
STUDY_PLAN.md         แผนฉบับอ่านง่าย สำหรับพิมพ์หรืออ่านโดยไม่ต้องเปิดเว็บ
```

การแก้ไข/เพิ่มเนื้อหา (เช่น เพิ่มสัปดาห์ที่ 13+) ทำได้โดยแก้ไฟล์ใน `webapp/data/*.js` ตามรูปแบบเดิม
